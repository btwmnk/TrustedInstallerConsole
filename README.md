# TrustedInstaller Console

CMD-подобная консоль, которая выполняет команды и запускает перетащенные файлы
под токеном **TrustedInstaller** уровнем прав выше обычного администратора.

Полезно, когда защищённые файлы, ключи реестра или установщики выдают
«Отказано в доступе» даже у админа.

## Возможности
- Получение токена TrustedInstaller цепочкой `winlogon (SYSTEM) → impersonate → TI`.
- Запуск под TI через `CreateProcessWithTokenW`.
- Drag & drop файлов в окно: `.msi`, `.exe`, `.reg`, `.bat`, `.cmd`, `.ps1`, `.vbs`, `.js`.
- Ввод команд как в обычном cmd (с сохранением текущей папки).
- Анимированная загрузка с проверкой личности токена.

## Сборка
Требуется .NET Framework 4.8 (встроен в Windows 10/11).

```bash
dotnet build -c Release
```
Или открыть `TrustedInstallerConsole.csproj` в Visual Studio и собрать в Release (x64).

## Использование
1. Запустить `.exe` **от имени администратора** (UAC запросится сам).
2. Перетащить файл в окно и нажать Enter — запустится под TrustedInstaller.
3. Или вводить команды напрямую. `whoami`, `cls`, `help`, `exit`.

Надёжный запасной способ: перетащить файл прямо на `.exe` или через «Отправить».

## Как это работает
Служба TrustedInstaller запущена под SYSTEM, но её токен содержит групповой SID
`NT SERVICE\TrustedInstaller`, который и даёт доступ к защищённым объектам.
Программа дублирует этот токен и выполняет под ним дочерние процессы.

## Требования
- Windows 10/11, x64
- Права администратора

## :warning: Предупреждение
Инструмент даёт максимальный уровень прав в системе. Запуск под TrustedInstaller
может необратимо повредить Windows при неосторожных командах.
Используйте на свой страх и риск, желательно на тестовой системе.
